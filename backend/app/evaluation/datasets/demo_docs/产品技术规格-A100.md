# 产品技术规格书：EdgeServer A100

**文档编号：DS-A100-2024 | 版本：Rev C | 发布日期：2024-03-01**

---

## 一、产品概述

EdgeServer A100 是一款面向中小型企业的边缘计算服务器，专为本地化 AI 推理、实时数据处理及企业私有云部署设计。A100 采用紧凑 1U 机架式设计，在有限空间内提供高效的计算能力，适合部署在网络边缘节点、分支机构机房或工厂车间。

### 1.1 典型应用场景

- 企业私有 AI 推理（图像识别、NLP 本地化部署）
- 工业 IoT 数据采集与实时处理
- 边缘视频分析（摄像头流处理，支持最多 **16 路** 1080P 并发）
- 分支机构本地化 IT 服务（DNS、DHCP、VPN 网关）
- 小型企业数据库服务（OLTP 负载）
