## 二、服务级别协议（SLA）

### 2.1 优先级定义

| 优先级 | 名称 | 定义 | 典型示例 |
|-------|------|------|---------|
| P0 | 紧急 | 影响全公司或多个核心部门，导致业务完全中断 | 公司网络瘫痪、邮件服务全面宕机、核心系统无法访问 |
| P1 | 高 | 影响一个部门或关键岗位，显著妨碍正常工作 | 某部门 VPN 无法连接、服务器宕机影响 20 人以上 |
| P2 | 中 | 影响单个用户，但有临时替代方案 | 单台电脑蓝屏、个人账号锁定、打印机故障 |
| P3 | 低 | 小问题或功能请求，不影响正常工作 | 软件安装申请、设备配件申请、咨询类问题 |

### 2.2 响应与解决时限

| 优先级 | 首次响应时限 | 解决时限 | 超时升级 |
|-------|-----------|---------|---------|
| **P0** | **15 分钟**（7×24 响应）| **2 小时**内恢复服务 | 30 分钟未响应自动升级至 IT 总监 |
| **P1** | **1 小时**（工作时间）| **4 小时**内解决 | 2 小时未响应升级至部门经理 |
| **P2** | **4 小时**（工作时间）| **1 个工作日**内解决 | 次日 EOD 未解决升级 |
| **P3** | **1 个工作日** | **3 个工作日**内解决 | 5 个工作日未解决升级 |

> **工作时间**：工作日 09:00–18:00；P0 全天候响应不受工作时间限制。

### 2.3 SLA 计算规则

- 响应时限从工单创建时刻开始计算。
- 等待用户提供信息的时间不计入 SLA 时钟（工单须标记"等待用户"状态）。
- 每月 SLA 达成率目标：P0/P1 **≥ 98%**，P2/P3 **≥ 95%**。

## 三、IT 工单提交流程

### 3.1 标准提交流程

1. 员工登录 IT 工单系统（https://helpdesk.company.com），点击「提交工单」。
2. 选择问题类别（设备 / 网络 / 账号 / 软件 / 其他），填写标题和详细描述。
3. 上传截图或错误日志（强烈建议，可加速处理）。
4. 选择影响范围（仅我自己 / 我的团队 / 多部门），系统自动建议优先级（可人工调整）。
5. 提交后收到邮件确认，工单号格式为 `IT-YYYY-XXXXX`（如 `IT-2024-00123`）。

### 3.2 工单跟进

- 员工可在工单系统中查看处理进度、追加留言。
- 工程师关闭工单后，员工须在 **3 个工作日**内确认，超期系统自动确认关闭。
- 如对处理结果不满意，可点击「重开工单」并说明原因。

## 四、常见故障处理

### 4.1 密码重置

**场景 A：记得旧密码，主动更换**
1. 登录企业微信 → 「IT 工具」小程序 → 「密码修改」。
2. 输入旧密码，设置符合策略的新密码（12 位以上，含大小写字母/数字/特殊字符），完成。

**场景 B：密码忘记或账号锁定**
1. 拨打 IT 服务台内线 **6688** 或发送企业微信消息至「IT 服务支持」群。
2. IT 工程师通过人脸识别或工牌验证身份后，远程重置密码。
3. 重置后系统发送临时密码至员工备用手机（入职时登记），首次登录强制修改。
4. 如备用手机也无法使用，须到 IT 服务台（B 栋 2 楼）现场核验身份。

**注意：禁止通过邮件或聊天工具传输密码（包括临时密码），必须走 IT 系统或现场核验。**

### 4.2 VPN 无法连接

**常见原因排查：**

| 症状 | 可能原因 | 处置方法 |
|------|---------|---------|
| 输入密码后报错「身份验证失败」| 密码错误或账号锁定 | 确认密码，或按 4.1 重置 |
| MFA 验证码输入后仍失败 | 手机时间不同步 | 同步手机时间后重试 |
| 连接后无法访问内网资源 | 路由问题 / 分割隧道配置 | 提交 P2 工单，附上 `traceroute` 结果 |
| 客户端报「证书过期」| GlobalProtect 客户端版本过旧 | 从 IT 服务台页面下载最新安装包（v6.2.x）|
| 连接超时（Timeout）| 网络运营商封锁 443/1194 端口 | 尝试切换为 GlobalProtect 备用端口 8443 |

**当前 VPN 服务器地址：`vpn.company.com`**
**备用地址：`vpn2.company.com`**

### 4.3 企业邮箱问题

**邮件无法收发：**
1. 检查 Outlook 右下角是否显示「已连接」（离线模式下邮件不会同步）。
2. 访问 https://mail.company.com 测试 Web 版，确认是客户端问题还是账号问题。
3. 若 Web 版也无法收发，提交 P1 工单。

**邮件误入垃圾箱：**
在 Microsoft 365 管理中心（需管理员权限）可查看传输记录；普通员工提交工单，IT 协助排查。

**邮箱配额告警（容量不足）：**
- 默认邮箱容量 **50 GB**，归档邮箱额外 **100 GB**。
- 超过容量 90% 时系统发送警告，超过 100% 后无法收信。
- 申请扩容须提交 P3 工单，经部门总监审批后扩容至 **100 GB**（最大）。

### 4.4 打印机故障

**打印机离线：**
1. 确认打印机电源和网线连接正常（或 WiFi 已连接，看打印机面板指示灯）。
2. 在电脑「打印机和扫描仪」设置中，选中对应打印机，点击「打开队列」→ 清空打印队列。
3. 重启打印机（长按电源键 5 秒关机，再开机）。
4. 如问题持续，提交 P2 工单，注明打印机编号（机身标签 `PR-XXX`）。

**驱动安装：**
- 公司打印机驱动统一通过 IT 工单系统下载（需登录，防止个人安装非授权驱动）。
- 新员工入职时 IT 工程师会预装常用打印机驱动，无需自行安装。

## 五、办公软件申请流程

### 5.1 标准软件（预批准列表）

以下软件无需审批，IT 工程师接单后 **1 个工作日**内安装：
- Microsoft Office 365 全套（Word/Excel/PowerPoint/Teams）
- Adobe Acrobat Reader（仅阅读版）
- Zoom / 腾讯会议
- 企业微信
- 7-Zip / Bandizip（压缩工具）
- Google Chrome / Mozilla Firefox

### 5.2 非标准软件

1. 提交 P3 工单，填写「软件安装申请」类别，写明软件名称、版本、官方下载链接、使用目的。
2. IT 安全团队评估（**3 个工作日**），不通过的附说明。
3. 评估通过后，IT 通过 MDM 推送安装，员工无法自行下载安装。
4. 付费软件须同时提交采购申请，金额 ≤ 500 元由部门经理审批，500–5,000 元由 IT 总监审批，>5,000 元须财务副总裁审批。

### 5.3 被拒绝的软件类型

以下类型软件不予审批，提交工单将被驳回：
- 破解/盗版软件
- P2P 下载工具（BitTorrent、迅雷）
- 游戏软件
- 未经国内备案的境外 VPN 工具
- 存在安全漏洞风险的老旧版本软件

## 六、设备借用规则

### 6.1 可借用设备清单

IT 设备库提供以下设备短期借用（最长 **5 个工作日**）：
- 备用笔记本电脑（Windows / macOS 各若干台）
- 外接显示器（27 英寸 4K）
- 视频会议摄像头（Logitech C930e）
- 便携式 USB-C 集线器
- 网线（Cat6，各长度）
- 电源适配器（85 W Type-C）

### 6.2 借用流程

1. 在 IT 工单系统提交「设备借用申请」，选择设备类型、借用日期和归还日期。
2. IT 管理员确认库存并审批（通常 **4 小时**内）。
3. 员工凭工单号到 B 栋 2 楼 IT 服务台领取，签署《设备借用确认单》。
4. 归还时 IT 工程师当场验收设备状态，无损归还即完成。

### 6.3 设备损坏与丢失

- 因正常使用造成的设备损耗，公司承担维修费用。
- 因员工失误（跌落、液体进入等）造成的损坏，员工承担**维修费用的 50%**，最高不超过 **2,000 元**。
- 设备丢失，员工赔偿该设备折旧后现值的 **80%**（设备折旧按 3 年线性计算）。
